# 💬 Messaging Website

A secure, real-time chat application built with **Vue.js** and the **Quasar Framework**, deployed with **Firebase**. It allows users to connect instantly, share messages and media, and track online presence in real time.

---

## 🚀 Features

- 🔐 **User Authentication**:  
  - New users register with name, email, and password 
  - Firebase Authentication stores credentials securely  
  - Users can log in on future visits

- 👥 **User List Page**:  
  - View all registered users  
  - See online status and last seen date  
  - Change your display name in real time  
  - Log out updates your status instantly in the database

- 💬 **Chat Interface**:  
  - Start one-on-one chats by clicking a user  
  - Offline users are labeled with a banner under their name  
  - Send messages including:
    - ✍️ Text  
    - 😊 Emoticons  
    - 🖼️ Images with preview and optional captions  
  - Messages show:
    - ✅ Sent (grey check) / ✅✅ Read (blue check) indicators  
    - 📅 Timestamp for each message  
    - 🕓 Dynamic labels: “Today,” “Yesterday,” weekday, or full date  
  - Delete individual messages or clear your side of the chat

- 🔁 **Realtime Updates**:  
  - Name changes, online status, and all messages sync instantly via **Firebase Realtime Database**

- 📊 **Active User Base**:  
  - Used by **50+ users** and growing

---

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Vue.js, Quasar Framework  
- **Backend**: Firebase Realtime Database  
- **Auth**: Firebase Authentication  
- **Deployment**: Firebase Hosting
